# Eze-Factory Agent Guide

Start with [`.agent/_index.md`](./.agent/_index.md), then open only the relevant guide under [`.agent/context/`](./.agent/context/).

Published installs include the stable agent guides and the package source under `lib/`, so their package-root-relative source paths remain inspectable from `node_modules/eze-factory`. Tests, release scripts, conversation handoffs, and internal refactor notes are intentionally not published.
